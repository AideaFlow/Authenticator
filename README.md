一个轻量级、隐私优先的 TOTP 两步验证码生成器，支持 Chrome 和 Edge 浏览器。

所有账户数据和密钥**仅存储在本地**，不会上传至任何服务器。

### 功能

- 生成基于时间的 TOTP 验证码
- 手动添加账户或扫描二维码绑定
- 自动扫描当前页面中的二维码
- 通过 ZIP 压缩包导入/导出数据
- 中英文界面切换
- 无网络访问，完全离线运行
