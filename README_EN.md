# Authenticator

**A Chrome/Edge Browser Extension**

[中文](./README.md)

---

A lightweight, privacy-first TOTP two-factor authentication code generator for Chrome and Edge browsers.

All account data and secret keys are stored **locally only** — nothing is ever uploaded to any server.

### Features

- Generate time-based TOTP verification codes
- Add accounts manually or by scanning QR codes
- Auto-scan QR codes from the current page
- Import/export accounts via ZIP archive
- Chinese/English interface switching
- No network access, fully offline
